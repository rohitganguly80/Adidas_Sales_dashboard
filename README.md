# Power BI Sales Dashboard

## Overview
This Power BI dashboard provides insights into sales performance, customer trends, and product analysis using interactive visualizations.

## Tools Used
- Power BI Desktop
- Excel (Data cleaning)


## Key Features
- Interactive slicers for year and region
- KPI cards for total sales, profit, and orders
- Trend analysis charts
- Top-performing products
